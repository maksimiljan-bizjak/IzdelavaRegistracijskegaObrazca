# Registration Form App

A simple Android registration form built with Java and XML in Android Studio.

## Features
- Enter personal details
- Select gender
- Accept Terms & Conditions
- Display entered details in a dialog

## Technologies
- Java
- Android Studio
- XML

Created as a school project to practise Android app development.
